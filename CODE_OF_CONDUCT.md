# Code of Conduct

We want this to be a friendly place to build a small, fun tool.

- Be kind and assume good faith. Critique code and ideas, not people.
- No harassment, discrimination or personal attacks, in issues, pull requests or anywhere that represents the project.
- Do not post other people's usage logs, API keys or private data.

This follows the spirit of the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). To report a problem, use GitHub's "Report content" on the comment or open a private security advisory for the repository and describe the conduct issue; the maintainer will review it and may edit, lock or remove content and block accounts.
